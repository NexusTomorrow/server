# Security policy

## Supported versions

NexusTomorrow has no releases yet. Security fixes land on `dev` and reach `main` with the next
promotion ([CONTRIBUTING.md](CONTRIBUTING.md#promotion-to-main)).

## Reporting a vulnerability

Please don't open a public issue for a security problem. Report it privately through GitHub
instead:

1. Go to the repository's **Security** tab.
2. Select **Report a vulnerability**.
3. Describe the problem: the affected project or file, how to reproduce it, and what an attacker
   could do with it.

The report stays private between you and the maintainers. We reply in the report, work on the fix
there, and credit you in the published advisory unless you'd rather not be named.

## Scope

In scope: the code in this repository, including its tools and its CI workflow.

Out of scope:

- the WildStar client itself;
- servers other people run from this code. Report those to whoever runs them.

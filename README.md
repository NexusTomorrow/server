# NexusTomorrow

A server for the WildStar client, build 16042, written in C# on .NET 10.

NexusTomorrow starts from the NexusForever project's `game_rework` branch, whose history it keeps,
and is building its own server core. It is in early development and does not run a game server yet.

## Requirements

- The .NET 10 SDK named in `global.json`.
- Your own WildStar 16042 client. No client files are distributed here.
